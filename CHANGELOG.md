# Changelog

## Unreleased

- 45 original examples added: 25 UI patterns, 14 optional effects, and six page sections.
- Opt-in patterns stylesheet, ESM initializer, cleanup API, and type declaration.
- Keyboard comparison and command search, scroll-snap carousel, bounded native
  steppers, reversible likes, validated multistep forms, and clipboard feedback.
- Shared pointer effects now support tilt and magnetic buttons without a new loop.
- Searchable reference snapshot covering 11 libraries and 1,744 catalog/index URLs,
  with related-pattern links and explicit partial-review notes.
- Expanded browser checks for interactions, mobile layouts, both themes,
  reduced motion, and static documentation packaging.
- Documentation chrome now uses Rofin inputs, buttons, navigation, badges,
  cards, grids, empty states, statistics, and footer styles.
- Command-palette Arrow Up starts at the last available command and wraps correctly.

- Added password reveal, tag input, character counter, searchable sortable table,
  launch checklist, and monthly/yearly billing examples.
- Browser-local saved collections with search and deduplicated setup copying.
- Sign-in and dashboard examples now reuse the password and table patterns.
- Form reset enhancements run after native reset and respect cancelled resets.

## 0.1.0

- 30 component examples built on scoped CSS and native HTML.
- Optional keyboard enhancements for tabs and popover menus; dialog triggers,
  tooltip dismissal, file-selection details, and text-only toast notifications.
- Lifecycle cleanup and automatic enhancement of inserted component subtrees.
- Six opt-in effects with reduced-motion support.
- Ten copyable page sections, plus landing page and dashboard examples.
- Searchable documentation with live previews, source code, setup instructions,
  theme switching, and mobile navigation.
- ESM, CommonJS, auto-initializing browser builds, modular imports, and types.
- Browser tests, automated accessibility checks, package validation, and build
  size reporting with an enforced core budget.

This is a pre-1.0 first release. npm publication is pending account authentication.
